Marksmith — transparent monitoring of managed AI tools
Transparency notice. This dashboard shows metadata, active-use time, and MASKED data-loss-prevention findings — conversation content is never captured for ordinary messages. Only when something is flagged, the surrounding message is also kept with the sensitive part(s) blanked in place, plus what share of the message they made up — enough to tell "a key accidentally pasted alongside other work" apart from "a key sent alone." Most matched values stay masked (a card shows only •••• 1234); an AWS Access Key ID is shown in full because it's an identifier, not the secret itself — see GOVERNANCE.md.
