# Marksmith 15-Second Demo Script & Shot List

This demo is designed for social media (Twitter/X, LinkedIn, Reddit) and Product Hunt. It focuses entirely on the "wait, it does THAT?" moments, specifically the math and diagram rendering.

**Total Time:** ~15 seconds  
**Format:** Fast-paced, screen-recorded, text overlays (no voiceover required, but upbeat background music recommended).

---

### Shot 1: The Problem (0:00 - 0:03)
* **Visual:** Split screen. Left side: ChatGPT window containing a complex matrix math block and a Mermaid flowchart. Right side: A blank Microsoft Word document.
* **Action:** Cursor highlights the ChatGPT output, hits `Ctrl+C`, clicks into Word, hits `Ctrl+V`. The result in Word is a disastrous, unreadable block of raw code and broken brackets.
* **Text Overlay:** Pasting AI into Word is a mess. ❌

### Shot 2: The Solution (0:03 - 0:06)
* **Visual:** Clean desktop. The Marksmith app (v1.4.1) window is open, showing its live editor.
* **Action:** Cursor pastes the exact same ChatGPT output into the left pane. Instantly, the right pane renders a beautiful, branded preview.
* **Text Overlay:** Enter Marksmith. ✨

### Shot 3: The Math "Wait, what?" Moment (0:06 - 0:10)
* **Visual:** Inside Microsoft Word, opening the exported document from Marksmith.
* **Action:** Zoom in on the math equation (a matrix or piecewise function). The cursor clicks *into* the matrix, proving it is a native Word OMML equation. The user types a number inside the matrix to prove it's fully editable.
* **Text Overlay:** Turns LaTeX into NATIVE, editable Word math. (Yes, even matrices). 🤯

### Shot 4: The Diagram "Wait, what?" Moment (0:10 - 0:13)
* **Visual:** Scroll down in the same Word document to the Mermaid flowchart.
* **Action:** The cursor clicks on one of the colored flowchart boxes. The Word "Shape Format" ribbon lights up. The cursor drags the box slightly to the side, proving it is a native, grouped Word shape, not a pasted PNG.
* **Text Overlay:** Rebuilds ALL Mermaid diagrams as editable Word shapes. 🎨

### Shot 5: Outro & Call to Action (0:13 - 0:15)
* **Visual:** The Marksmith logo with the tagline, running on a Windows 11 desktop background.
* **Text Overlay:** 
  100% Offline. Zero Cloud. Windows 11.
  Download Free at marksmith.app
